# Портфолио — Андрей (художник · декоративные покрытия)

Статический сайт-портфолио: авторская живопись («Арт») и декоративные
покрытия («Декоративка»). Без сборщиков и зависимостей — чистый HTML/CSS/JS.

## Как открыть

Просто откройте `index.html` в браузере (двойной клик) — сайт работает
даже с `file://`, потому что данные подключаются как `data/manifest.js`.

Либо запустите локальный сервер (рекомендуется для корректной работы видео):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html            — страница сайта
assets/css/style.css  — стили
assets/js/main.js      — галерея, фильтры, лайтбокс
assets/img/art/        — оптимизированные фото (Арт) + thumbs/ — превью
assets/img/decor/      — оптимизированные фото (Декоративка) + thumbs/
data/manifest.js       — список работ (генерируется автоматически)
scripts/build-assets.sh    — оптимизация фото и сборка манифеста
scripts/generate-manifest.js — генерация data/manifest.js
```

## Обновление фотографий

Исходники берутся из папок (можно переопределить переменными окружения):

- Арт: `/Users/akovnoskov/Desktop/Андрей/Арт`
- Декоративка: `/Users/akovnoskov/Desktop/Андрей/Декоративка`

Пересобрать ассеты после добавления новых фото:

```bash
./scripts/build-assets.sh
# или с другими папками:
ART_SRC="/путь/к/Арт" DECOR_SRC="/путь/к/Декоративка" ./scripts/build-assets.sh
```

Скрипт использует системную утилиту macOS `sips`:
уменьшает фото до 1800 px (полный размер) и 800 px (превью), пережимает в JPEG.

## Что можно поправить руками

- Тексты «Обо мне» и контакты — в `index.html` (секции `#about`, `#contact`).
  Ссылки Telegram / WhatsApp / Email сейчас заглушки — впишите свои.
- Цвета и шрифты — в `:root` файла `assets/css/style.css`.

## Публикация на GitHub Pages

Сайт — статический, все пути относительные, поэтому он работает и в
подпапке вида `https://<пользователь>.github.io/Decorative-artist/`.

1. Закоммитить и запушить файлы в ветку `main`:

   ```bash
   git add -A
   git commit -m "Портфолио: сайт и оптимизированные фото"
   git push -u origin main
   ```

2. На GitHub открыть репозиторий → **Settings** → **Pages**.
3. В разделе **Build and deployment** выбрать:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ral-design.github.io/Decorative-artist/`
   (адрес также покажется вверху страницы Pages).

Файл `.nojekyll` в корне отключает обработку через Jekyll — нужен, чтобы
GitHub Pages отдавал файлы как есть.

## Заметки

- В портфолио только фотографии. Видео намеренно не публикуются: на
  GitHub Pages действует лимит 100 МБ на файл и ограничение трафика, а
  ролики были тяжёлыми (до ~102 МБ). Если видео понадобится — лучше залить
  его на YouTube/Vimeo и вставить ссылкой.
